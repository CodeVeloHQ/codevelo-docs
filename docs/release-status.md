# Public release status

## Documentation status

This repository is the initial public documentation surface for CodeVelo. It describes
current services, the platform's architectural direction, and the responsibilities of
named applications without exposing private implementation details.

## Software availability

Most CodeVelo application and infrastructure repositories currently support internal
delivery and managed operations. They are not automatically open source because their
names or responsibilities appear in public documentation.

Before any software repository is released publicly, CodeVelo will review:

- ownership and licensing;
- repository history and secrets;
- client and infrastructure information;
- dependency and container provenance;
- documentation and clean-environment setup;
- security policy and support capacity; and
- long-term maintenance expectations.

## Likely public candidates

Public release work may begin with narrowly scoped documentation, examples, schemas,
templates, validation tools, and provider-independent integrations. Release decisions
will be made repository by repository rather than by copying the private platform into
GitHub wholesale.

No public release date is implied by this document.
